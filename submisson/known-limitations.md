# TransitOps - Known Limitations

The following features are planned for future development and may not be fully implemented in the current hackathon version.

## Current Limitations

### Frontend
- Some pages currently use mock data until full backend integration is completed.
- UI is optimized for desktop; further responsive refinements can be added.

### Backend
- Additional CRUD operations are planned.
- Advanced validation and error handling can be expanded.

### Fleet Features
- Live GPS vehicle tracking is not implemented.
- Route optimization is not implemented.
- Driver assignment automation is not implemented.
- Maintenance reminders are planned.

### Analytics
- Historical analytics can be expanded.
- Predictive maintenance models are planned.
- Cost optimization reports are planned.

### Notifications
- Email notifications
- SMS notifications
- Push notifications

### Security
- Role-Based Access Control (RBAC)
- Audit logs
- Multi-factor authentication (MFA)
