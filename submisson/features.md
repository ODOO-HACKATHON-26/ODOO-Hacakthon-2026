# TransitOps – Feature List

## Project Overview

TransitOps is a fleet and transport management system built for the Odoo Hackathon. It enables organizations to efficiently manage vehicles, drivers, trips, and fleet operations through a centralized dashboard.

---

## Core Features

### Authentication
- Secure Login
- JWT-based Authentication (Backend)
- Access Token Validation

### Dashboard
- Fleet Overview
- Key Performance Indicators
- Recent Trips
- Fleet Statistics

### Vehicle Management
- View Vehicles
- Search Vehicles
- Vehicle Status
- Add Vehicle (UI)

### Driver Management
- View Drivers
- Search Drivers
- Driver Status
- Add Driver (UI)

### Trip Management
- View Trips
- Search Trips
- Schedule Trips
- Trip Status

### User Interface
- Responsive Sidebar
- Dashboard Cards
- Status Badges
- Search Components
- Modular React Components
- Clean Navigation
